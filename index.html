    ERINNERUNGEN

    Das weiß Hermes über dich (0). Klick auf einen Eintrag, um ihn zu ändern. Leer lassen löscht ihn.

      DESIGN

      STIMME

      Klick auf eine Stimme spielt eine Probe und übernimmt sie. Die Online-Stimmen klingen natürlich, brauchen aber Internet (der Text geht dafür an Microsoft). „Lokal“ läuft komplett auf dem Laptop.

      WAKE-WORD

      Sag „Hey Hermes“, um ohne Klick ein Live-Gespräch zu starten (z.B. „Hey Hermes, wie wird das Wetter?“). Das Mikrofon hört dafür dauerhaft mit, erkannt wird alles lokal. „Stopp“ oder „Danke, das war's“ beendet das Gespräch.
